# Snapp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Snapp as the first installable Phone Store app, with a real local ride booking flow backed by the existing taxi, traffic, occupant, wallet, and save systems.

**Architecture:** `PhoneManager`/`PhoneScene` remain the sole modal owner. Snapp is a registry definition and Phone view; `TransportationSystem` owns a serializable Snapp booking record and extends the existing taxi runtime for dispatch, legal routing, payment, boarding, passenger travel, refunds, and safe completion. The Phone UI only calls narrow service APIs and observes immutable snapshots.

**Tech Stack:** TypeScript strict mode, Phaser 3 procedural UI/vehicle graphics, Vite/PWA, EventBus, ServiceLocator, ManagerRegistry, existing `TransportationSystem`, `TrafficSystem`, `VehicleOccupantSystem`, `InventoryComponent`, and `SaveManager`.

## Global Constraints

- Use the existing Phone, Store, taxi, traffic, occupant, wallet, save, localization, and overlay architecture; do not create parallel systems.
- Snapp is not preinstalled; Store is a built-in system app and remains installed.
- The Store catalog contains exactly one real entry (`snapp`) after this change and never lists Snapp after installation.
- No external APIs, network calls, third-party assets, icon libraries, or new runtime dependencies.
- All vehicle movement uses `TrafficSystem` legal route APIs; no teleporting or custom steering loop.
- Payment occurs before dispatch, is idempotent per booking/transaction, and refunds are idempotent.
- Phone opening pauses the world through existing `GameState.Paused`; booking simulation never runs while paused.
- User-facing strings are localized in every language currently supported by `Strings.ts`.
- Touch controls remain owned by `MobileControls`/`MobilePlatform`; Phone UI does not couple to them.
